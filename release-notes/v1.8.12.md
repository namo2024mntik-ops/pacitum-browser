# Pacitum Browser 1.8.12 (legacy edition)

This is the **legacy edition** on Qt 6.8 LTS, for computers that can't run Pacitum 1.9 (older graphics drivers, older Macs). Its updater only offers **1.8.x** releases, so it never moves you to a version your computer can't run.

If your computer can run it, **Pacitum 1.9.0** has a newer Chromium and Chrome extensions.

## 🐞 Fixes
- **Clicking "Update" closed Pacitum** (1.8.9–1.8.11). The update pop-up now opens.
- **The profile picture and ⋮ menu sat on top of the Back button** (1.8.11). They're back at the right end of the toolbar.
- The updater picks the installer that has a checksum file, so an extra file in a release can't be used by mistake.
- If the update helper can't start, Pacitum opens the normal Setup window instead of closing with nothing installed.
- Before installing, the updater waits for Pacitum's background processes to close, so Setup doesn't fail on locked files.
- Update steps are logged to `%TEMP%\PacitumUpdate\update.log`.

> **On 1.8.9, 1.8.10 or 1.8.11?** Clicking "Update" on the card crashes those versions. Click **Later** on the card, then click the update button in the toolbar. Or download Setup below and run it.

Everything from 1.8.11 is included: bookmark folders, the new animations and the security upgrades. Chrome extensions need Pacitum 1.9.
