# Pacitum Browser 1.9.0

Pacitum now comes in two editions built from the same code:
- **Pacitum 1.9.0 (this release)** uses **Qt 6.11** with a newer Chromium and runs **Chrome extensions**.
- **Pacitum 1.8.12** is the **legacy edition** on Qt 6.8, for computers that can't run 1.9 (older graphics drivers, older Macs).

## 🧩 Chrome extensions
- On a Chrome Web Store page, click **Add to Pacitum**. You can also add a `.crx`, a `.zip` or an unpacked folder from the 🧩 menu.
- Before adding, Pacitum lists what the extension may do.
- Pin an extension to the toolbar to open its pop-up. Switch it off or remove it from the same menu.

## 📁 Bookmark folders
- Folders on the bookmarks bar, with a drop-down list and "Open all".
- Right-click to create, rename, reorder or delete a folder.
- **Move to folder ▸**, or drag a bookmark onto a folder. Pick a folder right after pressing ☆.
- Folders sync with Google sync.

## ✨ Animations
- Menus, pop-ups and dialogs zoom out from where you opened them, with a soft bounce.
- New windows open with a growing circle.
- On macOS and Linux, windows shrink away when closed, drop when minimized and morph when maximized.

## 🔒 Security
- Windows: downloads are marked as "from the internet", so SmartScreen checks them.
- More file types that can run code wait for your OK before they open.
- The updater only installs releases with a SHA-256 checksum, downloaded over HTTPS from GitHub.
- Bookmarks are saved safely, so a crash while saving can't damage the file.

## 🐞 Fixes
- **Clicking "Update" closed Pacitum** (1.8.9–1.8.11). The update pop-up now opens.
- **The profile picture and ⋮ menu sat on top of the Back button** (1.8.11). They're back at the right end of the toolbar.
- If the update helper can't start, Pacitum opens the normal Setup window instead of closing with nothing installed.
- Before installing, the updater waits for Pacitum's background processes to close, so Setup doesn't fail on locked files.
- Update steps are logged to `%TEMP%\PacitumUpdate\update.log`.
- The reload button's spin animation now plays.
- `localhost:3000` and IP addresses like `192.168.1.1:8080` open instead of being searched.

> **On 1.8.9, 1.8.10 or 1.8.11?** Clicking "Update" on the card crashes those versions. Click **Later** on the card, then click the update button in the toolbar. Or download Setup below and run it.
